# 七影画布 Flowspace

## 软件简介

七影画布是一款 Windows 桌面软件，把 AI 短剧从剧本到成片的各环节放在同一块无限画布上，以节点形式编排：剧本 → 脚本 → 参考图 → 关键帧 → 视频片段 → 合成成片。每个节点的提示词、引用图和状态都留在画布上，可回看，也可接着上次继续跑。

- 可直连自建或云端 ComfyUI；设为默认后出图优先走该实例，不再调用云端 API。
- 提示词模板分用途、美术风格、模型三层，内置默认可直接用，改完可存为自己的模板，也能一键恢复默认。
- 内置 20 种美术风格：真人实拍、纪实市井、复古胶片、暗黑悬疑、3D 国漫、仙侠 CG、国风插画、赛璐璐、厚涂、赛博朋克等。
- 可开启「额度用完即停止」，模型无额度即停止，不继续产生费用；工程和素材保存在本机。

## 下载与安装

- 官网：https://lis212-cloud.github.io/QiYingcanvas/
- 安装包：https://github.com/lis212-cloud/QiYingcanvas/releases/latest
- 平台：Windows 10 / 11 64 位；运行需 WebView2（Win11 自带）。
- 下载 NSIS 安装程序后双击安装，带开始菜单和卸载项；ffmpeg 与技能资源已打包在内。

## 使用步骤

1. 安装后打开软件，在项目列表新建项目，或导入已有项目。
2. 在画布中粘贴或导入剧本。
3. 由智能体拆解场次与节拍，生成脚本和分镜。
4. 进入设置配置模型：填 ComfyUI 地址并设为默认，或填入云端模型 API Key；文本模型无额度时，分镜走本地规则兜底。
5. 生成角色、场景、道具参考图，在画布上确认后作为资产复用。
6. 基于参考图生成各镜关键帧，再生成视频片段。
7. 在画布上检查节点状态与提示词，确认后合成成片并导出。
8. 提示词需要调整时，到「设置 → 提示词模板」按用途、风格、模型三层修改；图像提示词写英文，视频提示词可用中文。

## 数据与说明

- 画布数据、资产表、模板配置保存在本机；参考素材存放在项目素材库，不上传第三方服务器。
- 卸载前如需保留工程，请先导出画布与素材。
- 当前安装包未做代码签名，首次运行 SmartScreen 会提示未知发布者；确认安装包来源为本仓库后，选择「更多信息 → 仍要运行」即可。

## 技术栈

Tauri v2 + Rust + WebView2，前端原生 JavaScript，无前端框架。
